# ATM Service Implementation Task

## Overview

Develop an ATM (Automated Teller Machine) service that handles cash withdrawals and deposits while managing concurrent
access to shared resources.

## Requirements

### Core Functionality

1. Support for banknote denominations: 10, 20, 50, 100
2. Implement cash withdrawal functionality
3. Implement cash deposit functionality
4. Maintain accurate account balances
5. Validate transaction amounts and available funds

### Additional Requirements

1. Handle multiple concurrent transactions safely
2. Ensure thread-safe balance updates
3. Implement cash withdrawal with optimal banknote distribution
